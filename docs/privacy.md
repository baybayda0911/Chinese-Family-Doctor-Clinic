# 本地资料、授权与两个设备

每台设备有独立档案库，放在源码仓库之外。成员使用随机代号；身份映射另在本地保存。JSON为主数据，Markdown仅派生视图。目录与提示词是受控操作约定，不能保证同账户Agent无法访问其他文件。

同成员指定一个primary_vault_id，副本readonly_replica；副本新观察/更正作为proposal交主库确认，不争抢权威版本。转移主库须显式核对最后版本与备份，不自动执行。

人工交换：
1. 选择成员、记录类别/日期、敏感范围及接收库，展示内容集中授权。
2. 导出最小摘要，包含包/记录标识、revision、来源、确认及指纹。默认不含原件、身份映射、绝对路径、文化记录或未授权心理/生育细节。
3. 用户自行选择传输渠道；工具不自动上传、发邮件或创建共享链接。
4. 接收时校验目标库、成员映射、版本、指纹、范围和差异；主库确认合入，副本保持只读。
5. 重复包幂等；同记录同revision不同内容阻止覆盖；版本缺口、主库不一致或范围外记录进入复核。

同日独立观察不按日期去重；不同数值不平均；不同单位不静默替换。哈希用于完整性/重复识别，不能代替认证。当前没有自动同步、端到端加密或身份认证服务。

模型只接收本次脱敏、已核对的最少内容，模型服务仍会处理这些敏感健康片段。公开检索只使用通用主题；原始报告不上传第三方OCR/解析。MCP内部读取原件的路径和输出也不进入模型。脱敏效果必须由本地预览核对，不能只检查JSON字段名。

成年档案默认私密，按成员/类别授权共享。心理、生育细节不默认汇总。当前受控两设备场景不建立复杂权限系统；未来开放家属自助前验证账户/文件/工具隔离，覆盖检索、导出、缓存、日志、附件及备份。

每批正式写入/合并前生成可恢复快照，备份同样敏感且默认本地。恢复先保留有效库、验证schema/来源/版本，再确认。删除、轮换、保留期、共享与同步需要明确配置，本基线不自动处理。
