# 来源审阅与医学规则

来源登记在 [source-register.json](../.agents/skills/chinese-family-doctor-clinic/references/source-register.json)。登记代表发现公开资料，不表示原附件逐条审阅、医学有效或仍完整现行。上游评分、剂量和相关系数不直接启用为自动判断。

状态：discovered → retrieved → reviewed → approved_for_scope → superseded/withdrawn。只有approved_for_scope并匹配地区、人群、阶段、版本与任务的规则可作为对应范围自动检查依据。当前没有批准的自动医学规则。

每条规则应有rule_id、source_id、具体条款/页码、发布/实施日期、版本、地区、人群、替代关系、审阅者/日期/批准范围。高影响规则优先由相应医学专业审阅；未审阅保留候选状态。项目没有承诺已具备临床审阅团队。

覆盖表至少包括症状风险、儿童成长/接种、孕期日常与既有医嘱、心理初筛/危机、成人慢病、单位标准化。几条候选指南不能替代完整覆盖表；不自造个体阈值、剂量或量表计分。

公开检索核对具体任务来源与最新适用版本，保存URL及检索日期。不联网时标最后核查时间，不宣称最新。建议定期复核登记，发现替代版本立即将相关规则标待复核。文化、古籍、教材与医家经验单独分层，不与现代安全依据混作同一证据等级。

测试结果分开报告：功能、识别质量、医学规则复核、隐私处理、临床验证。本文不是临床验证方案批准，也不能据Schema通过宣称具有诊疗能力。
