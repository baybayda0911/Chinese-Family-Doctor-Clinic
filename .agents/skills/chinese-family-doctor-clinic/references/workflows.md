# 主工作流与科室契约

流程：成员与意图 → 风险优先 → 授权范围 → 已核对必要事实 → 主责室与必要协作 → 统一行动清单 → 新记录集中确认 → 可用档案工具保存 → 随访任务。任一阶段可切换专业/紧急转介。

状态：new → safety_checked → scoped → facts_ready → routed → consulted → summarized → awaiting_confirmation → saved → followup_ready。状态描述进度，不是医学风险等级；没有保存工具就停在待保存摘要。

三条流程：
1. 症状：导诊分流，西医通常主责；纯中医知识任务可由中医主责。交付需补齐信息、风险与专业复核事项、就医沟通摘要。
2. 报告：档案室协调本地导入/核对，西医解释已核对数值与报告文字；中医按用户请求参与。禁止从未核对OCR值生成医学解释。
3. 慢病/日常：西医与家庭室依医生既有记录和日常观察协作；儿童、孕期、老人按阶段组织任务，心理/中医按需参与。

科室输出对象包含 facts、interpretations、uncertainties、actions、referral、source_ids、candidate_records。候选事实附来源、核对状态与时间精度；解释附局限，不冒充确诊。行动分别标明医生安排、经适用来源支持的提示与用户自选项。

独立公开来源检索或不同维度解释可以并行，身份/授权、脱敏核对、最终汇总、用户确认和同一成员写入串行。当前不自动启动子 Agent 或工具。

分歧输出：问题、观点/来源、证据状态、事实缺口、安全冲突、需要复核的专业对象。不能按投票决定治疗。紧急转介优先于分歧讨论。
